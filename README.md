# .707 — 144-0 like KBO All-time Draft Game

1982~2025년 KBO 정규시즌의 실제 선수 기록으로 18명(또는 29명)의 팀을 드래프트하고, 그 팀으로 144경기 시즌을 치르는 웹 게임입니다. 목표는 KBO 역대 최고 승률인 1985년 삼성의 .706을 넘는 **.707**입니다.

[144-0 — KBO 올타임 드래프트](https://github.com/DrunkJin/kbo-144-0)(DrunkJin)와 82-0 같은 무패 시즌 드래프트 게임에서 영감을 받은 독립 프로젝트입니다. 시즌 기록은 같은 저장소가 정리한 Kaggle KBO Player Dataset을 사용했습니다.

---

## 빠른 시작

Node.js 18 이상만 있으면 됩니다. 외부 패키지는 쓰지 않습니다(`npm install`이 아무것도 받지 않습니다).

```bash
npm run dev      # 빌드 후 http://localhost:3000 에서 실행 (PORT=8080 npm run dev 로 포트 변경)
npm run build    # dist/index.html 생성 → 아무 정적 호스팅에나 올리면 됨
npm run export   # data/exports/player_seasons.csv 재생성 (선수-시즌 원자료를 읽기 쉬운 표로)
npm run extract  # 빌드된 단일 HTML에서 data/ 를 역으로 뽑아냄 (HTML을 직접 고친 경우)
```

`dist/index.html`은 게임 코드·데이터·폰트가 모두 들어간 **한 파일**입니다. 그대로 열어도 동작하고, 외부 요청은 Google Fonts뿐입니다.

`vercel.json`이 빌드 명령(`npm run build`)과 출력 폴더(`dist`), 보안 헤더를 정해 둡니다.

`npm run build` 후 `dist/` 폴더를 올리면 됩니다. Netlify(Build command `npm run build`, Publish directory `dist`), Cloudflare Pages, GitHub Pages 모두 같은 방식입니다.

## 저장소 구조

```
src/index.html         게임 본체(HTML·CSS·JS). 데이터와 폰트 자리에 자리표시자가 있음
data/                  게임이 읽는 데이터 (JSON) — 구조는 data/README.md
  moneyball/           머니볼 모드 가격 데이터
  exports/             사람이 보기 위한 표(CSV) — 게임은 읽지 않음
assets/fonts/          Galmuri14 픽셀 폰트 서브셋 (SIL OFL 1.1)
public/                dist/ 에 그대로 복사되는 파일 (robots.txt)
scripts/               build · dev · export · extract (의존성 없는 Node 스크립트)
```

빌드는 `src/index.html`의 `/*__DATA__*/`에 `data/`의 JSON을 하나의 객체 `D`로 합쳐 넣고, `/*__FONT_GALMURI14__*/`에 폰트를 base64로 넣습니다. 데이터만 고칠 때는 `data/`의 JSON을 바꾸고 다시 빌드하면 됩니다.

## 게임 구조

### 진행
1. **룰렛:** 시즌(연도)과 구단을 무작위로 뽑습니다. 그 팀의 그 시즌 선수 중 한 명을 골라 빈 자리에 넣습니다. 한 이닝(초·말)이 한 픽입니다.
2. **드래프트:** 야수 9명(포수·1루·2루·3루·유격·좌·중·우·지명), 선발 5명, 구원 3명, 마무리 1명으로 18명을 채웁니다. 외국인은 투수 2명·타자 1명까지(KBO 규정)입니다.
   - 다시 돌리기는 게임당 3번이며, 시즌만 또는 구단만 골라 다시 돌릴 수 있습니다.
   - 같은 선수는 시즌이 달라도 한 번만 뽑습니다. 이미 지명한 연도는 룰렛에 다시 나오지 않습니다.
3. **타순:** 9명의 타순을 정합니다. 1번은 출루와 주력, 4·5번은 장타력처럼 역할에 맞으면 가산점이 붙습니다.
4. **결과:** 팀의 144경기 기대 승률과 승패, 시즌 예측 기록(선수별 타율·홈런·평균자책·승·세이브 등), 실제 시즌에 이 팀을 넣었을 때의 순위·시상(시즌 리뷰)을 보여줍니다.

### 채점 엔진 (요약)
- **타자:** 그 시즌 리그 대비 wOBA를 사건별(단타·2루타·3루타·홈런·볼넷·사구·삼진)로 나누고, 사건마다 안정되는 속도에 맞춰 표본이 적을수록 대체 선수 쪽으로 당깁니다. 삼진은 일반 아웃보다 0.012점 더 나쁘게 칩니다.
- **투수:** 평균자책과 FIP를 반반 섞은 실점률을 리그 대비로 바꾸고, 같은 방식으로 표본·실력 보정을 합니다(풀타임 선발은 리그 평균과의 차이 약 50%를 인정).
- **시대 보정:** 리그 수준 편차가 컸던 1980년대 기록은 최근 10년 리그의 편차로 환산합니다(1982년 타자 0.72배, 투수 0.80배).
- **출장:** 타자는 그 시즌 실제로 소화한 타석 비중(55~96%), 선발은 선발 등판 비중(55~97%)만큼만 뛰고 나머지는 백업이 채웁니다.
- **수비:** 2001년 이후 KBO 수비 기록의 포지션별 출장·실책률로 수비 가능 위치와 실책 위험을 정하고, 낯선 자리에는 감점이 있습니다.
- **좌우:** 2001년 이후 상황별 기록으로 선수별 좌·우 상대 성적을 반영합니다.
- **승수:** 득점·실점을 Pythagenpat 기대승률에 넣고, 무승부(경기당 약 3.1%)를 빼 KBO 순위표 방식으로 승률을 냅니다.

세부 수치와 근거는 게임 화면의 "채점 방식" 설명과 `src/index.html`의 엔진 주석에 있습니다.

### 머니볼 가격 (요약)
- **2005~2025년:** 그 시즌 개막 전 연봉 순위로 기본 가격을 정합니다(20위까지 5코인, 40위 4, 60위 3, 150위 2, 그 밖 1).
  - 연봉 상위권·외국인 상위권은 실제 연봉, 나머지는 성적·역할·나이로 역산한 추정치입니다. 2025년은 구단 발표 연봉을 추가로 반영했습니다.
  - FA·다년 계약은 옵션을 뺀 보장액 연평균을 씁니다.
  - 보정: 직전 시즌 5 WAR 이상 +1, 풀타임 0.5 WAR 미만 −1, 명성 가산(최근 MVP, 직전 골든글러브·개인 타이틀, 프랜차이즈 스타; 최대 +1). 직전 MVP·투수 골든글러브는 5코인.
- **1982~2004년:** 실제 연봉 자료가 드물어 연봉 흐름을 재현합니다.
  - 직전 시즌 WAR로 매년 연봉이 오르내리게 하되 인상 60%·삭감 25% 상한을 둡니다. 신문 기사로 확인된 고액 연봉자는 상위권에 고정합니다.
  - 그 순위를 구단 수에 맞춰 등급으로 바꾼 뒤 2005년 이후와 같은 보정을 붙입니다.
- **공통:**
  - 신인 하한: 계약금 상위 유망주·데뷔 시즌 신인왕. 달력 기준 기간이며 군 복무만 연장합니다.
  - 풀타임 최소 2코인, 직전 국가대표 +1(4코인까지).
  - 변동 완충: 바깥 사정 없이 한 해짜리 가산만 사라질 때는 −1까지, 근거 없이 오를 때는 +2까지만 움직입니다.
  - 개별 지정값이 있습니다. 목록은 `data/exports/coin_adjustments.csv`입니다.
- **효율 채점:** 실제 구단 328개(18명 기준)의 핵심 선수단 몸값과 승률로 그은 기준선 대비 몇 승을 더 했는지로 순위를 매깁니다.

시즌별 계산 근거(연봉·순위·보정 내역)는 `data/exports/coin_trace_*.csv`에 있습니다.
