# data/

게임이 읽는 데이터입니다. `npm run build`가 `manifest.json`의 순서대로 파일을 읽어 객체 `D` 하나로 합치고, `src/index.html`에 넣습니다. 키 이름이 곧 `D`의 속성 이름입니다(`D.rows`, `D.mb.pay` …).

용량을 줄이려고 선수-시즌은 배열로 압축돼 있습니다. 사람이 보기 쉬운 표는 `exports/player_seasons.csv`(`npm run export`로 재생성)를 쓰면 됩니다.

## 기본 테이블

| 파일 | 형태 | 내용 |
|---|---|---|
| `rows.json` | 배열의 배열 (한 줄 = 한 선수-시즌·구단) | 아래 "rows 구조" |
| `names.json` | 문자열 배열 | 선수 이름. `rows`의 이름 인덱스가 가리킴 |
| `teams.json` | 문자열 배열 | 구단 이름(그 시즌 이름). 시즌 중 개명·합병은 `삼미·청보`, `해태·KIA`처럼 한 이름 |
| `pos.json` | 문자열 배열 | 대표 포지션 코드 `1B 2B 3B C CF CL DH LF RF RP SP SS` |
| `pos8.json` | 문자열 배열 | 수비 포지션 순서 `C 1B 2B 3B SS LF CF RF` (비트마스크·수비 배열의 기준) |
| `fr.json` | `{구단: 계보코드}` | 프랜차이즈 계보(OB→두산 `DS`, 해태→KIA `KIA`, 삼미~키움 `HD` …). 룰렛과 아이콘 판정에 씀 |
| `hb.json` | `{선수ID: [투타, 생년월일]}` | 투타는 `RR`·`RL`·`LL`·`RuR`(우언더) 등, 생년월일은 `YYYYMMDD` |
| `lg.json` | `{연도: [지표…]}` | 리그 평균 맥락(아래 "lg 구조") |
| `sp.json` | `{선수ID: {연도: 값}}` | 좌우 스플릿 보정값(그 시즌 리그 wOBA 대비, 2001년~) |
| `st.json` | `{연도: [[구단, 승, 패, 무], …]}` | 2015~2025 실제 순위표(시즌 리뷰용) |
| `field.json` | `{포지션: [실책률, 기회 계수]}` | 리그 평균 수비 기준 |

### rows 구조

`[t, nameIdx, teamIdx, yearOffset, posIdx, id, war100, posMask, field, foreign, ...stats]`

| 위치 | 이름 | 뜻 |
|---|---|---|
| 0 | `t` | 0 = 타자, 1 = 투수 |
| 1 | `nameIdx` | `names.json` 인덱스 |
| 2 | `teamIdx` | `teams.json` 인덱스 |
| 3 | `yearOffset` | 연도 − 1982 |
| 4 | `posIdx` | `pos.json` 인덱스(대표 포지션) |
| 5 | `id` | 선수 ID(시즌·구단을 넘어 같은 사람) |
| 6 | `war100` | WAR × 100 |
| 7 | `posMask` | 수비 가능 포지션 비트마스크(`pos8.json` 순서, 1비트 = C) |
| 8 | `field` | `[주포지션 인덱스, (숙련도%, 실책률×10, 신뢰도%) × 포지션 수]` |
| 9 | `foreign` | 1 = 외국인 |
| 10~ | `stats` | 타자 14개 / 투수 13개 |

- **타자 stats:** `PA AB H 2B 3B HR RBI BB HBP SO SB GDP IBB SF` (기록이 없는 시대의 GDP는 −1)
- **투수 stats:** `outs ER H HR BB HBP SO GS SV W G IBB L` (outs = 이닝 × 3)

같은 선수가 한 시즌에 두 구단에서 뛰면 구단별로 한 줄씩입니다.

### lg 구조 (주요 인덱스)

| 인덱스 | 내용 |
|---|---|
| 0 | 리그 wOBA |
| 1 | 리그 평균자책 |
| 2 | FIP 상수 |
| 7~13 | 타석당 단타·2루타·3루타·홈런·볼넷·사구·삼진 비율 |
| 16 | 타석당 고의4구(2001년 이전 0) |
| 17 | 타석당 병살(모르면 −1) |
| 18 | 선발 1회 등판당 아웃 |
| 19 | 구원 1회 등판당 아웃 |
| 20 | 경기 수 계수(그 시즌 경기 수 ÷ 144) |
| 21·22 | 타자·투수 시대 편차 환산 계수 |

나머지 인덱스는 보조 리그 지표로, `src/index.html` 엔진 주석에 쓰임이 적혀 있습니다.

## moneyball/

| 파일 | 내용 |
|---|---|
| `pay.json` | 2005~2025 가격. `c[연도][선수ID]` = 규칙으로 계산된 코인, `ov` 개별 지정(`ID\|연도` → 코인, 마지막에 적용), `sm` 변동 완충(`ID\|연도` → [완충 전, 완충 후]), `nt` 직전 국가대표(+1, 4코인까지), `tr` 시즌 중 트레이드 할인, `fcap` 공개 연봉 10위 밖 외국인 상한, `ft` 풀타임 최소 코인, `y0` 시작 연도 |
| `pre.json` | 1982~2004 국내 선수 가격(연봉 흐름 재현 + 보정 결과). `ID\|연도` → 코인 |
| `preov.json` | 1982~2004 개별 지정 |
| `big.json` | 2004년 이전 대형 신인(입단 동기 최고 계약금) `ID → 입단 연도` |
| `roy.json` | 신인왕 `ID\|연도` 목록 |
| `royx.json`, `royx_note.json` | 데뷔 시즌이 아닌 중고 신인왕 등 신인왕 하한 제외 대상과 사유 |
| `bonus.json` | 계약금 `ID → [만원, 입단 연도]` |
| `bp.json` | 계약금의 입단 동기 내 백분위(또는 그 해 평균 연봉 대비 환산) |
| `fapre.json` | 2004년 이전 FA 계약 하한 `ID\|연도 → 코인` |
| `cut.json` | (구) 이름값 등급 경계 — 현재 1982~2004 국내 선수 가격은 `pre.json`이 대신함 |
| `nobonus_note.json` | 계약금 대우에서 뺀 선수와 사유 |
| `hist.json`, `hist29.json` | 실제 구단의 `[연도, 구단, 핵심 18명(29명) 몸값, 승률]` — 효율 채점 기준선 |

게임 안 가격(`coinOf`)은 이 값들 위에 규칙을 차례로 적용해 나옵니다. 적용 순서는 다음과 같습니다.
1. 기본값(`pay.c` 또는 `pre`)
2. 신인 하한·FA 하한
3. 풀타임 최소
4. 국가대표 +1
5. 트레이드 할인
6. 변동 완충
7. 개별 지정

## exports/ (참고용, 게임은 읽지 않음)

| 파일 | 내용 |
|---|---|
| `player_seasons.csv` | `rows.json`을 풀어 쓴 선수-시즌 표 (`npm run export`) |
| `coins_by_player.csv` | 선수별·시즌별 개막 코인, 시즌 중 재가격, 최고·평균 코인 |
| `coins_by_season.csv` | 선수-시즌-구단별 코인, 편집 지정·완충 여부 |
| `coin_trace_2005-2025.csv` | 2005년 이후 가격 계산 근거(비용·출처·순위·보정·하한·이유) |
| `coin_trace_1982-2004.csv` | 2004년 이전 재현 연봉·순위·보정 |
| `coin_adjustments.csv` | 개별 지정·변동 완충 전체 목록 |
| `fa_contracts_2000-2025.csv` | FA·다년 계약(보장액, 기간, 옵션) |
| `national_team_bonus.csv` | 국가대표 +1 적용 목록과 대회 |
| `salary_anchors_pre2005.json` | 2004년 이전 연봉 고정용 기사 수집본(출처 URL 포함) |

`coins_*`·`coin_*` 파일은 현재 빌드 시점의 스냅샷입니다. `data/`를 고친 뒤에는 게임 화면의 값이 기준입니다.
